# 通用思维导图格式规范与符号速查手册

本手册汇总了面向**任意知识领域**（理工科技、工程研发、艺术设计、音视频创作、人文商业等）构建高密度、去废话、多模态思维导图的核心标准。确保生成的 Markdown 在 **XMind（移动端与桌面端）导入时 100% 零报错且图文并茂**，并在 **自包含交互式 HTML** 中提供现代化的流畅体验。

---

## 1. 核心格式兼容与呈现矩阵

| 特性 | XMind (Markdown 导入) | Markmap (交互式 HTML / IDE) | 本工作流落地规范 |
| :--- | :--- | :--- | :--- |
| **中心主题** | 首行 `# 根主题` 映射为唯一中心气泡 | 根节点 | **全篇必须且只有 1 个 `#` 根标题** |
| **分支层级** | `##` $\rightarrow$ `###` $\rightarrow$ `####` $\rightarrow$ `#####` | 树形分支逐级展开 | **统一使用 Markdown 多级标题构建主干与枝叶** |
| **末尾标点** | 结尾带句号会破坏节点美观 | 无影响，但不带句号更紧凑 | **各级节点末尾一律严禁加句号（。或 .）** |
| **数学/量化公式** | 不支持 LaTeX（易乱码或解析报错） | 原生不支持 LaTeX | **全面转换为规范 Unicode 符号表达** |
| **多模态图片** | 原生支持相对路径并内嵌于节点气泡 | 原生渲染并自适应缩放 | **采用 `![批注说明](./images/xxx.png)`** |
| **对比微表格** | 原生支持 Markdown 表格并内嵌 | 原生渲染二维结构 | **支持在节点下嵌入 2×2 / 3×3 对比小表格** |

## 2. 知识原子化与通用展开范式

思维导图的本质是将线性的视频叙述转化为**树状的结构化认知网络**。根据知识属性，采用以下两种通用的原子化展开范式：

### 2.1 范式一：概念、原理与机制型展开（适合理论、科学、架构与设计模型）
逻辑收敛链路：
$$\text{核心概念 (英文全称/缩写/词源): 本质与定义} \longrightarrow \text{底层原理 / 运行机制 / 构成要素} \longrightarrow \text{定量参数 / 评估指标 / 效果输出}$$

```markdown
### 核心概念或技术架构 (Term Name)
#### 核心定义与本质：准确说明其解决的问题与底层定义，标注官方原名或词源
#### 底层机制与流转逻辑
##### 关键要素 A：输入条件、转换过程与产出结果
##### 关键要素 B：核心算法、约束规则与协作机制
##### 定量关系与公式：Unicode 表达的数学/物理/逻辑推导式
#### 方案局限与适用边界：适用场景与不可用条件
```

### 2.2 范式二：操作、步骤与工具型展开（适合实操、软件使用、工作流与工程管线）
递进操作链路：
$$\text{操作目标 (工具/方法名称): 核心作用} \longrightarrow \text{标准语法 / 执行步骤 [必要输入] [可选参数]} \longrightarrow \text{参数选项 / 注意事项: 边界条件与避坑}$$

```markdown
### 操作目标或指令名称 (Tool / Command)
#### 标准操作语法：command [参数选项] [目标对象]
##### -参数 A：具体控制效果、默认行为与边界约束
##### -参数 B：进阶调节选项与典型使用场景
#### 阶段输出与验收标准：执行完成后的预期产物与验证方法
```

### 2.3 范式三：多维对比与选型微表格（适合横向对比多方案、多策略）
在需要横向对比时，在三级或四级分支下直接嵌入原生 Markdown 表格：
```markdown
#### 核心方案横向对比与选型准则
| 对比维度 | 方案 A | 方案 B | 选型与决策建议 |
| :--- | :--- | :--- | :--- |
| **核心机制** | 机制简述 | 机制简述 | 适用倾向 |
| **性能/成本** | 定量指标 | 定量指标 | 资源考量 |
| **典型局限** | 主要短板 | 主要短板 | 避坑提醒 |
```

## 3. 多模态视觉锚定与图片挂载规范

### 3.1 为什么需要视觉锚定？
思维导图的拓扑本质是**树形分支**，而现实视频中的高密度知识往往存在纯文字难以优雅表达的**非树形结构**：
- **状态跃迁与转换逻辑**（如状态机三角、生命周期状态转移、通信握手与挥手）；
- **闭环流转与反馈回路**（如生化循环、控制论反馈环、工作流闭环）；
- **系统架构与多维拓扑网络**（如软件系统分层架构、网络拓扑、复杂微观结构）；
- **密集走带与复杂界面**（如 DAW 编曲音轨工程走带、仪器操作面板、Nature 级复合排版图表）。

### 3.2 图像截取与存储规范
- **存储路径**：存放在与思维导图同级的 `images/` 子文件夹中。
- **命名规范**：`<主题>_<关键知识点>_annotated.png`。
- **Markdown 语法**：
  ```markdown
  ##### ![图解简述说明](./images/xxx_annotated.png)
  ```
  在 XMind 中导入时，该节点将直接呈现为带有图解的图文混排气泡。

## 4. 跨学科通用 Unicode 符号对照表

在 XMind 中严禁使用 LaTeX 标记（如 `$ ... $`），必须统一转换为标准的 Unicode 符号：

### 4.1 常用上下标与数学运算符
| 类别 | 常见概念 | 规范 Unicode 表达 |
| :--- | :--- | :--- |
| **上标/乘方** | 平方、立方、n次方、负幂次 | `x², y³, 2ⁿ, e⁻ˣ, O(n²)` |
| **下标/对数/角标** | 常用对数、自然对数、数列通项 | `log₁₀(P), log₂(N), aₙ, xᵢ, H₂O, CO₂` |
| **运算符** | 乘、除、正负、等价、近似、正比 | `×, ÷, ±, ∓, ≡, ≠, ≈, ∝` |
| **不等关系** | 大于等于、小于等于、远大于、远小于 | `≥, ≤, ≫, ≪` |
| **根号与微积分** | 平方根、立方根、求和、连乘、积分、偏导、梯度 | `√x, ∛x, ∑, ∏, ∫, ∬, ∂, ∇` |
| **几何与集合** | 属于、包含、交集、并集、空集、无穷、垂直、角度 | `∈, ∉, ⊂, ⊃, ⊆, ∩, ∪, ∅, ∞, ⊥, ∠, △` |
| **推导与箭头** | 反应推导、可逆、充分必要、因为所以 | `→, ←, ⇄, ⇒, ⇔, ∴, ∵, ↦` |

### 4.2 常用希腊字母表
| 大写 | 小写 | 常见科学/工程含义 |
| :--- | :--- | :--- |
| **$\Alpha$ / $\alpha$** | `Α / α` | 显著性水平、透明度、学习率、衰变、结构型 |
| **$\Beta$ / $\beta$** | `Β / β` | 二类错误、测试版、折叠结构、系数 |
| **$\Gamma$ / $\gamma$** | `Γ / γ` | 伽马射线、增益、欧拉常数 |
| **$\Delta$ / $\delta$** | `Δ / δ` | 增量变动 $\Delta$、狄拉克函数 $\delta$、化学位移 |
| **$\Theta$ / $\theta$** | `Θ / θ` | 角度、模型参数 $\theta$、渐进紧确界 $\Theta(n)$ |
| **$\Lambda$ / $\lambda$** | `Λ / λ` | 波长、特征值、正则化惩罚系数 |
| **$\Mu$ / $\mu$** | `Μ / μ` | 微米 $\mu$、均值、摩擦系数、突变率 |
| **$\Pi$ / $\pi$** | `Π / π` | 圆周率、连乘 $\prod$、策略函数 |
| **$\Sigma$ / $\sigma$** | `Σ / σ` | 求和 $\sum$、标准差 $\sigma$、Sigmoid 函数 |
| **$\Omega$ / $\omega$** | `Ω / ω` | 欧姆、角速度、复杂度下界 $\Omega(n)$ |

## 5. 去废话与节点修剪黄金法则

1. **删减所有引导修饰词**：彻底删除“我们需要注意”、“众所周知”、“简单来说”、“一般而言”、“这里主要介绍了”等所有冗余语言。
2. **标签化短语呈现**：善用 `机制: ...`、`优势: ...`、`局限: ...`、`规则: ...`、`参数: ...`。
3. **保留中英文对照**：如 `快速傅里叶变换 (FFT, Fast Fourier Transform)`，提升专业度与权威性。
4. **末尾绝对不加句号**：无论是多级标题还是末梢叶子，结尾绝不加 `。` 或 `.`。
